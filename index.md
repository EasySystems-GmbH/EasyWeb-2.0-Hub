# EasyWeb 2.0 Hub

Welcome to the public EasyWeb 2.0 documentation hub.

## What's in EasyWeb 2.0

- **CMS admin** — pages (hybrid GrapesJS + Monaco editor), image sliders, navigation, image gallery, documents, data sets, news, forms, theme, users, settings
- **Fine-grained permissions** — control which editors can change pages, images, nav, and settings
- **Liquid themes** — Fluid templates with SEO, navigation, and slider placeholders
- **CLI & VS Code** — full CMS-via-CLI (`publish` / `pull`, settings, images, documents, backup, users, secrets, API tokens); `easyweb help` prints this hub URL
- **Docker** — run locally or on ESYS Hosting with PostgreSQL
